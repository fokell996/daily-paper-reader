## 摘要
我们开发了一种用于贝叶斯脉冲星计时与噪声分析的序贯集合MCMC方案，该方案以数据规模作为回火参数。该方法通过迭代增加数据规模，使算法能够从可能无信息的初始点逐步且可靠地收敛，从而提高灵敏度并逐步收窄目标分布，直至到达完整数据集的后验分布。初始迭代使用可比完整数据集小若干数量级的子数据集，从而大幅降低计算成本；由于这些子数据集的灵敏度降低，采用近似的低秩模型还可进一步降低计算成本。在施加适当预热后，使用从真实目标分布采样得到的最终MCMC链进行贝叶斯推断。我们使用PSR B1855+09的NANOGrav 12.5年数据演示了该方法，展示了其向目标后验的逐步收敛，并表明大部分计算时间用于对真实目标分布进行采样，而非用于此前的回火迭代。

## Abstract
We develop a sequential ensemble MCMC scheme for Bayesian pulsar timing and noise analysis that uses data size as the tempering parameter. The method enables gradual and reliable convergence from potentially uninformed initial points by iteratively increasing the data size, thereby increasing sensitivity and progressively narrowing the target distribution until the posterior of the full dataset is reached. The initial iterations use sub-datasets that can be orders of magnitude smaller than the full dataset, substantially reducing computational cost, which is further lowered by employing approximate lower-rank models justified by the reduced sensitivity of these sub-datasets. Bayesian inference is performed using the final MCMC chain sampled from the true target distribution after applying appropriate burn-in. We demonstrate the method using the NANOGrav 12.5-year data of PSR B1855+09, showing progressive convergence to the target posterior and that most of the computational time is spent sampling the true target distribution rather than in the preceding tempered iterations.

## 1. 论文的核心问题与整体含义

- **研究动机**：脉冲星计时是探测纳赫兹引力波、检验引力理论、研究中子星物态等的重要手段；脉冲到达时间（TOA）同时受确定性计时模型和随机噪声过程影响。
- **核心问题**：传统脉冲星噪声贝叶斯分析常采用线性化计时模型，以降低计算成本并便于解析边缘化或 Gibbs 采样。但计时模型本质非线性，部分参数先验也不适合解析边缘化；在需要全非线性计时与噪声联合推断时，MCMC/嵌套采样面临三大挑战：
  - 非线性计时模型计算昂贵，部分情形需数值求解微分方程；
  - 参数维度高，可达数百；
  - 后验几何复杂，常呈尖峰、Neal 漏斗等形态，导致收敛慢且对初值敏感。
- **整体含义**：论文提出一种以“数据规模”为回火参数的序贯集合 MCMC 方案，旨在从可能无信息的初值出发，稳健、高效地收敛到全数据非线性计时与噪声后验，为大规模脉冲星计时和 PTA 分析提供实用采样工具。

## 2. 论文提出的方法论

- **核心思想**：不直接用逆温度 \(\beta\) 回火似然，而是用数据子集大小作为回火参数。定义逐步增大的数据序列  
  \(D_1 \subset D_2 \subset \cdots \subset D_S \equiv D\)，以及对应的低秩近似模型序列  
  \(M_1 \subset M_2 \subset \cdots \subset M_S \equiv M\)。
- **计算成本依据**：
  - 脉冲星计时似然为  
    \(\ln L = -\frac12 r^T C^{-1} r - \frac12 \ln \det[2\pi C]\)，其中 \(C = N + F\Phi F^T\)。
  - 用 Woodbury 恒等式和矩阵行列式引理，主要计算量来自 \(F^T N^{-1}F\)，复杂度约 \(O(np^2)\)。
  - 实际数据中噪声秩 \(p\) 随数据量 \(n\) 增长，因此全数据后验计算量超线性增长；论文图 1 显示大 \(n\) 时近似 \(O(n^3)\) 渐近。
  - 子数据集 \(D_s\) 使用低秩模型 \(M_s\)，其评估成本可显著低于全数据模型，且后验更宽、更易采样。
- **算法流程**：
  1. 给定 \(W\) 个初始点、各阶段后验 \(P[\theta|D_s,M_s]\)、burn-in 比例 \(\beta_s\) 和各阶段步数 \(l_s\)；
  2. 对 \(s=1,\dots,S\)：
     - 从当前初始点运行 \(l_s\) 步集合 MCMC；
     - 丢弃前 \(\beta_s l_s\) 步；
     - 从剩余链中随机抽取 \(W\) 个唯一样本，作为下一阶段初始点；
  3. 最终仅返回 \(s=S\) 阶段、即真实全数据后验 \(P[\theta|D,M]\) 的链，丢弃 \(\beta_S l_S\) 步后用于推断。
- **集合采样实现**：使用 `emcee`，结合 stretch move 和 differential evolution move。
- **随机重采样而非端点传递的原因**：脉冲星后验可能存在难采样区域，部分链会“卡住”。若用上一阶段端点作为下一阶段初值，卡住的链必然传递；随机抽取可降低其存活概率，随迭代数增加，卡住链存活概率趋于 0。
- **与似然回火对比**：
  - 似然回火定义 \(P_\beta \propto P[D|\theta,M]^\beta P[\theta|M]\)，\(\beta\in[0,1]\)；
  - 数据回火的优势是子集评估成本更低，尤其适合大数据；缺点是子数据集随机选择，可能包含全数据后验中不存在的特征。
- **实现**：代码公开于 `https://github.com/abhisrkckl/vela-sdt`。
