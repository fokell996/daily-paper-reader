## 摘要
我们开发了一种置换不变的 Set Transformer，用于从可变大小、无序的中子星（NS）观测集合中重建致密物质的物态方程（EoS）。该模型输入恒星质量以及半径、潮汐形变度或二者兼有，并在固定密度网格上预测压强 P(n) 或声速平方 c_s^2(n)，同时给出依赖于密度的不确定度。架构中没有任何部分规定哪颗恒星为哪个密度提供信息：自注意力以非线性方式耦合所有观测，每个密度点通过其自身可学习的查询读取整个集合，因此恒星到密度的映射是从数据中学习得到的。该模型在独立的分段多方和高斯过程 EoS 系综上训练，能够给出校准良好的预测，其不确定度在稳定恒星无法探测的密度区域增大。重建误差随观测数量增加而减小，而在固定观测数量下，潮汐形变度通常能提高精度，即使其本身带有测量噪声。敏感性分析揭示了一种密度局域映射：在压强模型中，密度 n 处的预测最强烈地依赖于中心密度接近 n 的恒星。我们还表明，模型对推断出的恒星致密度的敏感性提供了关于最小中心密度的信息。这些结果表明，基于集合的神经推断——其中恒星到密度的映射是学习得到而非假设的——能够提取具有校准不确定度的、物理上可解释的 EoS 信息。

## Abstract
We develop a permutation-invariant Set Transformer to reconstruct the equation of state (EoS) of dense matter from variable-size, unordered sets of neutron star (NS) observations. The model takes stellar masses together with radii, tidal deformabilities, or both, and predicts either the pressure $P(n)$ or the sound speed $c_s^2(n)$ on a fixed density grid, along with density-dependent uncertainties. Nothing in the architecture prescribes which star informs which density: self-attention couples all observations nonlinearly, and each density point reads the full set through its own learnable query, so the star-to-density mapping is learned from the data. Trained on independent piecewise-polytropic and Gaussian-process EoS ensembles, the model provides well-calibrated predictions whose uncertainty increases in density regions that stable stars cannot probe. Reconstruction errors decrease with the number of observations, while tidal deformability generally improves accuracy at a fixed observation count, even when it carries its own measurement noise. Sensitivity analysis reveals a density-local mapping: in the pressure models, predictions at density $n$ depend most strongly on stars whose central densities are near $n$. We also show that the sensitivity of the model to the inferred stellar compactness provides information on the minimum central density. These results demonstrate that set-based neural inference, in which the star-to-density mapping is learned rather than assumed, can extract physically interpretable EoS information with calibrated uncertainties.

- **核心问题**：如何从有限、无序、可变数量的中子星观测中重建致密物质物态方程（EoS），并给出密度依赖的不确定度。

- **方法动机**：传统贝叶斯推断虽能给出后验，但计算昂贵，观测集变化后需重复分析；普通神经网络多要求固定长度输入，不自然尊重观测集合的置换不变性与可变大小。
- **整体含义**：论文提出用置换不变的 Set Transformer，把恒星观测视为集合，让模型自行学习“哪颗星约束哪个密度”，从而快速、可解释、带校准不确定度地推断 EoS。

## 2. 方法论

- **核心思想**：输入一个无序观测集合，每个元素表示一颗恒星的 \(M\) 与 \(R\)、\(\Lambda\) 或二者；模型在固定密度网格上输出 \(P(n)\) 或 \(c_s^2(n)\)，并同时预测每个密度点的不确定度。
- **输入表示**：
  - 每个观测编码为四维特征 \(x_i=(M_i,R_i,\Lambda_i,\mathbb{1}_\Lambda)\)。
  - 半径观测写作 \((M_i,R_i,0,0)\)；潮汐形变观测写作 \((M_i,0,\Lambda_i,1)\)；二值标志 \(\mathbb{1}_\Lambda\) 标识测量类型。
  - 不使用位置编码，因此模型对集合顺序置换不变。
- **网络结构**：
  - 两层 MLP 将每个集合元素嵌入到 \(d=128\) 维。
  - 编码器由两个 Set Attention Block（SAB）组成，每个包含四头自注意力、残差连接、LayerNorm 和逐元素 MLP。
  - 池化采用 Pooling by Multi-head Attention（PMA），使用 \(k=20\) 个可学习种子向量作为 query，对编码集合做交叉注意力。
  - 展平为 \(k\cdot d=2560\) 维，经两层 MLP 解码器输出 20 个密度点的均值 \(\hat\mu_j\) 和 log 方差 \(\log\hat\sigma_j^2\)。
- **输出目标**：
  - 压力目标：预测 \(\log_{10}\hat P(n_j)\)。
  - 声速目标：直接预测 \(\hat c_s^2(n_j)\)。
  - 异方差高斯头给出密度依赖不确定度；另设确定性 MSE 基线模型。
- **训练损失**：
  - 主损失为高斯负对数似然：
    \[
    \mathcal L=\frac1B\frac1J\sum_{i=1}^B\sum_{j=1}^J
    \frac12\left[\log\hat\sigma_{ij}^2+\frac{(y_{ij}-\hat\mu_{ij})^2}{\hat\sigma_{ij}^2}\right]
    \]
  - 先做 10 个 epoch 的 MSE warm-up 拟合均值，再启用方差项。
- **训练设置**：
  - AdamW，学习率 \(10^{-3}\) 余弦退火，weight decay \(10^{-4}\)，batch size 64，梯度裁剪 1.0，训练 200 epoch。
  - 每个 mini-batch 随机抽取 \(N\sim U\{5,\dots,35\}\) 颗星；质量在 \([0.8M_\odot,M_{\max}]\) 均匀采样；噪声每 epoch 重采样。
  - 半径由 \(R(M)\) 三次样条计算；\(\Lambda\) 通道先取 \(\log_{10}\Lambda\) 再标准化。
- **敏感性分析**：
  - 定义逐星、逐密度的 Jacobian 敏感度 \(s_{Mj}(n_i)=\partial\hat P(n_i)/\partial M_j\)，\(s_{Rj}(n_i)=\partial\hat P(n_i)/\partial R_j\)，并在集合内归一化。
  - 进一步组合为无量纲敏感度：
    \[
    s_j(n_i)=M_j s_{Mj}(n_i)+R_j s_{Rj}(n_i)
    =\frac{\partial\hat P(n_i)}{\partial\ln M_j}+\frac{\partial\hat P(n_i)}{\partial\ln R_j}
    \]
  - 通过质量分箱和系综平均得到 \(p(\text{star}|n)\)，并比较质量坐标与致密度 \(C=GM/(Rc^2)\) 坐标。
