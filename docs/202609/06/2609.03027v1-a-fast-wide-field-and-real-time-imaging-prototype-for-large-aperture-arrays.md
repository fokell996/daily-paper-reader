## 摘要
亚毫秒时间尺度的实时处理对于探测快速射电暴（FRB）和引力波并合瞬变电磁对应体等快速天体物理瞬变事件至关重要。即时定位能够实现快速多波段后随观测，最大化科学回报。因此，实时能力已成为现代宽视场孔径阵列的关键要求，这些阵列正日益以数千至数万天线单元的规模部署。然而，传统相关器架构的计算规模为\mathcal{O}(N^2)，给大规模N阵列带来了巨大的计算、带宽和功耗挑战。这些限制通常会缩小视场、降低角分辨率或缩短观测占空比，最终降低瞬变源的发现潜力。利用电场并行成像“相关器”（EPIC）直接对全视场成像，绕过了成对相关的显式形成，提供了一种有前景的替代方案。EPIC可实现稠密孔径阵列的\mathcal{O}(N \log N)计算扩展，并已在位于美国塞维莱塔的长波阵列（LWA）台站上通过图形处理单元（GPU）得到验证。然而，GPU实现可能受限于低比特网格化和快速傅里叶变换（FFT）工作负载中的内存带宽。因此，我们正在开发一种基于现场可编程门阵列（FPGA）的EPIC原型实现，利用高度并行的FFT流水线来提高计算效率并降低功耗。基于初步结果，我们评估了其性能，特别是从可扩展性的角度，并讨论了其适用于包括SKA-Low和中频孔径阵列在内的下一代仪器的适用性。

## Abstract
Real-time processing on sub-millisecond timescales is essential for detecting fast astrophysical transients such as fast radio bursts (FRBs) and prompt electromagnetic counterparts to gravitational-wave mergers. Immediate localisation enables rapid multi-wavelength follow-up and maximises scientific return. As a result, real-time capability has become a key requirement for modern wide-field aperture arrays, which are increasingly being deployed at scales of thousands to tens of thousands of antenna elements. However, traditional correlator architectures scale as $\mathcal{O}(N^2)$, creating significant computational, bandwidth, and power challenges for large-$N$ arrays. These constraints often limit field of view, angular resolution, or observing duty cycle, ultimately reducing transient discovery potential.   Direct imaging of the full field of view using E-field Parallel Imaging ``Correlator'' (EPIC) offers a promising alternative by avoiding the explicit formation of pairwise correlations. EPIC can achieve $\mathcal{O}(N \log N)$ computational scaling for dense aperture arrays and has been demonstrated on the Long Wavelength Array (LWA) station in Sevilleta (USA) using Graphics Processing Unit (GPU). However, GPU implementations can be limited by memory bandwidth in low-bitwidth gridding and Fast Fourier Transform (FFT) workloads. We, therefore, are developing a prototype implementation of EPIC using Field Programmable Gate Arrays (FPGA) that exploits highly parallel FFT pipelines to improve computational efficiency and reduce power consumption. Using preliminary results, we evaluate its performance particularly from the viewpoint of scalability, and discuss its suitability for next-generation instruments including SKA-Low and mid-frequency aperture arrays.
