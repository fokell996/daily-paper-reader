## 摘要
当前射电望远镜的数据率约为 O(10) PB/年，预计未来射电望远镜（如 SKA）还会增长一个数量级。应对这些数据流需要数据管理范式的转变：构建模块间具有密集 I/O 的流水线（离线模式）正变得不可持续，从而推动向实时范式过渡，即通过 PSRDADA 环形缓冲区等方式将数据移入 RAM。我们的目标是获得一个紧凑的流水线，以高效管理实时流中的数据，同时最小化 HPC 资源。我们采用 Heimdall，这是一个执行非相干消色散的开源检测流水线，用于检测射电天文数据中的单脉冲，例如 FRB——一类起源尚未完全解释的天体物理信号。Heimdall 目前可在单块 GPU 上处理单个波束，并且既能以离线模式也能以实时模式运行，输入可为 SIGPROC filterbank 文件或 PSRDADA 环形缓冲区。我们使用在 Medicina 附近的 Northern Cross 射电望远镜 NS 臂的 16 个柱面收集的数据，分别以离线和实时模式运行测试流水线，以比较所得结果和性能。为验证这些测试，我们采用不同的输入数据并探索问题的参数空间。对于表征 FRB 的最重要量（TOA 和 DM），PSRDADA 与 SIGPROC 结果通常一致到 3% 以内，而对于 SNR，一致到 10% 以内。在包含真实 FRB 的数据的大多数运行中，PSRDADA 模式的执行时间保持在实时流内，但在该测试平台设置下，它们通常仍与 SIGPROC 模式相当。该测试在准确性和性能方面提供了重要的初步比较：这项工作为下一步将波束形成器与 Heimdall 流水线集成提供了功能和准备，该集成具有与测试流水线相同的逻辑结构，相关工作已在推进中。

## Abstract
Data rates from current radio telescopes are of $\sim$O(10)PB/y and we expect a growth of an order of magnitude for future radio telescopes, e.g. SKA. Coping with these data flows requires a paradigm change in data management: building pipelines with intense I/O between their modules (offline mode) is becoming unsustainable, leading to a transition to a real-time paradigm, where data are moved to RAM, e.g.,through PSRDADA ring buffers. Our objective is to obtain a compact pipeline to efficiently manage data in the real-time flow, while minimizing HPC resources. We employ Heimdall, an open source detection pipeline that performs incoherent de-dispersion, to detect single pulses in radio astronomy data, such as FRBs, astrophysical signals whose origin has not been completely explained. Heimdall currently processes a single beam on a single GPU and can operate both in offline and real-time modes, reading in input either a SIGPROC filterbank file or a PSRDADA ring buffer. We run a test pipeline with data collected from 16 cylinders of the NS arm of the Northern Cross radio telescope near Medicina, both in offline and real-time modes, to compare the obtained results and performance. To corroborate these tests, we employ different input data and explore the problem's parameter space. PSRDADA and SIGPROC results generally agree within 3% for the most important quantities characterizing a FRB (TOA and DM) and within 10% for the SNR. Execution times in PSRDADA mode stay in the real-time flow for most runs from data containing true FRBs but they are still generally comparable with SIGPROC mode in this testbed setup. This test provides an important preliminary comparison in terms of accuracy and performance: this work is functional and preparatory for the next integration of the beamformer with the Heimdall pipeline, having the same logical structure as the test pipeline, work already in progress.
