## 摘要
脉冲星计时阵列（PTA）对质量范围在$10^{-24}$-$10^{-20}\,\mathrm{eV}$的超轻暗物质（ULDM）敏感，现有数据集已探测到其他开放参数空间，而未来的PTA有望大幅提高探测能力。然而，迄今为止，PTA对ULDM的搜索通常采用极限描述。分析要么在完全相关极限下进行（即阵列共享局部ULDM振幅），要么在完全不相关极限下进行（即每颗脉冲星具有独立的局部振幅）。由于这两种机制之间的转变发生在PTA敏感质量范围内，投影灵敏度和数据推导的约束可能取决于所假设的极限描述。我们首次开发了一种自洽分析，将ULDM场视为具有有限空间相关性的高斯随机场，从而允许PTA信号模型中使用的振幅先验在完全相关和完全不相关极限之间连续插值。我们将该框架应用于线性和二次耦合标量ULDM，后者包括由振荡ULDM压力产生的普遍引力信号。通过扩展潜场先验纳入脉冲星距离不确定性，并使用归一化流代理表示距离边缘化后的潜振幅分布。我们在模拟PTA数据集上验证了该方法，包括盲信号注入测试。

## Abstract
Pulsar timing arrays (PTAs) are sensitive to ultralight dark matter (ULDM) in the $10^{-24}$-$10^{-20}\,\mathrm{eV}$ mass range, with existing datasets already probing otherwise open parameter space and future PTAs promising substantial improvements in reach. Thus far, however, PTA searches for ULDM have typically been formulated using limiting descriptions. Analyses are performed in either the fully correlated limit, in which the local ULDM amplitude is shared across the array, or the fully uncorrelated limit, in which each pulsar has an independent local amplitude. Because the transition between these regimes occurs within the PTA-sensitive mass range, projected sensitivities and data-derived constraints can depend on which limiting description is assumed. For the first time, we develop a self-consistent analysis that treats the ULDM field as a Gaussian random field with finite spatial correlations, allowing the amplitude prior used in PTA signal models to interpolate continuously between the fully correlated and fully uncorrelated limits. We apply the framework to both linearly and quadratically coupled scalar ULDM, the latter including the universal gravitational signal sourced by the oscillating ULDM pressure. Pulsar-distance uncertainties are incorporated through an augmented latent-field prior, and the resulting distance-marginalized latent-amplitude distribution is represented with a normalizing-flow surrogate. We validate the method on mock PTA datasets, including blinded signal injection tests.

- **整体含义**：现有约束依赖于人为选择的极限假设，可能导致对耦合强度的限制出现误解。本文首次提出一个**自洽分析框架**，将ULDM场视为具有有限空间相关性的高斯随机场，使振幅先验在两个极限之间连续插值，从而消除对极限假设的依赖，获得更可信的物理约束。

#### 2. 论文提出的方法论

- **核心思想**：
  - 利用ULDM场的统计性质（高斯随机场），通过空间两点相关函数刻画地球和脉冲星处场值之间的有限相关性。
  - 构造“增强潜场先验”（augmented latent-field prior）：将脉冲星距离用于计算相关包络（缓慢变化），而将有效相位 $\psi_I$ 视为独立的均匀分布讨厌参数（快速变化），从而避免遍历康普顿波长尺度的相位涨落。
  - 推导出潜振幅 $A$ 的联合先验 $\pi(A|m_\phi)$，并用**归一化流（normlizing flow）** 进行近似表示，实现高效采样。
  - 对线性耦合信号，时序残差线性依赖于场；对二次耦合信号（包括引力信号），残差正比于场的平方（快速模式振荡频率为 $2m_\phi$），但潜振幅先验相同，仅响应映射不同。

- **关键技术细节**：
  - **场协方差**：在单色近似下，延迟时域场 $\hat\phi_I(t)$ 的两点相关函数：
    $$\langle \hat\phi_I(t) \hat\phi_J(t')\rangle = \frac12 \cos[m_\phi\Delta t - \psi_I + \psi_J]\, R_{IJ}, $$
    其中 $R_{IJ}=\exp(-\Delta x_{IJ}^2/2\ell^2)$ 为空间相关包络，$\psi_I=m_\phi x_I$ 为相位延迟。
  - **高斯振幅统计**：将 $\hat\phi_I(t)$ 展开为正弦余弦系数 $(\hat C_I,\hat S_I)$，其协方差由复重叠约化函数 $\hat\Gamma_{IJ}=R_{IJ}e^{-i(\psi_I-\psi_J)}$ 决定。
  - **增强潜场先验**：对每个固定质量 $m_\phi$，先根据脉冲星距离先验抽取距离，计算 $R_{IJ}$；再独立均匀抽取有效相位 $\psi_I$（$I\ge1$，地球相位固定为零）；构造高斯系数协方差，变换得到振幅 $A$ 和物理相位 $\alpha$。边缘化后，$\alpha$ 独立均匀，$A$ 的联合分布 $\pi(A|m_\phi)$ 由归一化流代理。
  - **归一化流**：采用神经样条流（8个变换，隐藏层宽256，16个样条桶），对每个质量单独训练；先通过解析映射将瑞利边缘变为标准正态，再用流学习剩余相关性。训练使用Adam，学习率 $10^{-3}$，批量大小2048，余弦退火，1000个epoch。
  - **贝叶斯推断**：在固定质量网格上进行MCMC采样（使用`pocomc`，一种t-Crank-Nicolson采样器），联合估计潜振幅 $A$、潜相位 $\alpha$、总体振幅参数（$A_\phi$ 或 $A_E,A_P$）以及背景噪声参数（白噪声、红噪声、SGWB）。流先验用于直接采样或通过变换引入。

- **场景**：
  - **零信号测试**（null test）：无注入ULDM信号，用于获取95%置信上限灵敏度曲线。
  - **非盲注入测试**（unblinded injection）：注入已知质量（$2.2\times10^{-24}$、$2.2\times10^{-23}$、$2.2\times10^{-22}\,\mathrm{eV}$）和振幅的ULDM信号，检验恢复能力。
  - **盲注入测试**（blinded injection）：注入未知质量（范围$10^{-24}$–$10^{-22}\,\mathrm{eV}$）和振幅的信号，分析者不知注入参数，检验质量网格搜索的识别能力。

  - 完全不相关极限分析（$\ell\to0$）；
  - 本文有限相关分析（基准）。
- **评估指标**：95%上限置信水平、后验分布覆盖度、贝叶斯证据（用于盲测试质量定位）。
